{% comment %} Reusable "active filters" badge row with a clear control. Expects (passed in via {% include ... with %}): - clear_url: REQUIRED. Resolved URL that drops every filter, e.g. from {% url ... as clear_url %} - node_label: Label for the alphabet badge (e.g. 'Title' for books, 'Last name' for authors) - hx_target: OPTIONAL. When set, the clear control also gets hx-* attributes and swaps that target instead of doing a full page load. - group_clear_target: OPTIONAL. When set, every active filter group renders its own `Clear` control that swaps this selector. Read from the inherited context: - selected_langs, selected_genres: selected filter codes, used only to decide whether to render - active_languages, active_genres: Language/Genre objects for the badges - active_alphabet_node: the resolved alphabet tree node, if any - filter, regex: raw alphabet filter values, used as a fallback badge Pages without language/genre filtering simply leave those keys undefined; the loops then render nothing and the guard falls through to `filter or regex`. {% endcomment %}
